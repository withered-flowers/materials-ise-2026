## 1. Cheatsheet Perintah Dasar Git & GitHub

| Perintah | Deskripsi Fungsi |
| :--- | :--- |
| `git init` | Menginisialisasi repositori Git baru pada direktori folder lokal saat ini. |
| `git status` | Memeriksa kondisi berkas (berkas baru, berkas diubah, atau berkas dalam staging area). |
| `git add .` | Menambahkan seluruh perubahan berkas ke ruang persiapan (*staging area*). |
| `git commit -m "pesan"` | Menyimpan rekaman riwayat perubahan (*snapshot*) dengan keterangan yang jelas. |
| `git branch -M main` | Menamai branch utama proyek menjadi `main`. |
| `git remote add origin <URL>` | Menghubungkan repositori lokal dengan repositori remote di GitHub. |
| `git push -u origin main` | Mengunggah riwayat commit lokal ke branch `main` di GitHub untuk pertama kali. |
| `git push` | Mengunggah commit terbaru ke GitHub setelah remote origin terhubung. |
| `git pull` | Mengambil dan menggabungkan pembaruan kode terbaru dari GitHub ke komputer lokal. |

## 2. Cheatsheet Perintah Netlify CLI

| Perintah | Deskripsi Fungsi |
| :--- | :--- |
| `npx netlify-cli login` | Membuka jendela browser untuk proses otentikasi login ke akun Netlify. |
| `npx netlify-cli status` | Memeriksa informasi akun yang aktif dan status tautan situs yang terhubung. |
| `npx netlify-cli dev` | Menjalankan server pengujian lokal di komputer Anda pada alamat `http://localhost:8888`. |
| `npx netlify-cli deploy` | Merilis website ke lingkungan **Draft / Preview** untuk pengujian sebelum rilis resmi. |
| `npx netlify-cli deploy --prod` | Merilis website secara langsung ke lingkungan **Production (Live URL)**. |
| `npx netlify-cli sites:list` | Menampilkan seluruh daftar situs web yang terdaftar di akun Netlify Anda. |

## 3. Ambang Batas Metrik Google Lighthouse (Core Web Vitals)

| Indikator Metrik | Kategori Baik (Hijau) | Perlu Peningkatan (Oranye) | Kategori Buruk (Merah) |
| :--- | :--- | :--- | :--- |
| **LCP (Largest Contentful Paint)** | ≤ 2,5 detik | 2,5 – 4,0 detik | > 4,0 detik |
| **INP (Interaction to Next Paint)** | ≤ 200 ms | 200 – 500 ms | > 500 ms |
| **CLS (Cumulative Layout Shift)** | ≤ 0,1 | 0,1 – 0,25 | > 0,25 |
| **Skor Keseluruhan Kategori** | 90 – 100 | 50 – 89 | 0 – 49 |

## 4. Matriks Penyelesaian Masalah (Troubleshooting)

### 1. Halaman Menampilkan "404 Page Not Found"
- **Gejala**: Ketika membuka tautan URL situs Netlify, muncul halaman bertuliskan *Page Not Found*.
- **Penyebab**:
  1. Berkas HTML utama tidak bernama `index.html` (misalnya bernama `home.html` atau `Index.html`).
  2. Pengaturan `publish` directory pada `netlify.toml` atau Netlify Dashboard tidak mengarah ke lokasi berkas `index.html`.
- **Solusi**:
  - Pastikan berkas utama bernama persis `index.html` (seluruhnya huruf kecil).
  - Jika berkas berada di akar folder, pastikan baris konfigurasi `publish = "."` pada `netlify.toml`.

### 2. Tampilan CSS Tidak Muncul atau Gambar Tidak Tampil
- **Gejala**: Halaman web hanya berupa teks polos tanpa warna, styling tata letak berantakan, atau gambar tidak termuat.
- **Penyebab**: Tag HTML menggunakan jalur berkas absolut dari penyimpanan lokal komputer pengembang (misalnya: `href="C:/Users/Dokumen/proyek/style.css"`).
- **Solusi**:
  - Ganti seluruh pemanggilan berkas menjadi jalur relatif sederhana, seperti `<link rel="stylesheet" href="style.css">` dan `<img src="gambar.webp">`.

### 3. Kendala Git: "fatal: remote origin already exists"
- **Gejala**: Muncul pesan error saat menjalankan `git remote add origin <URL>`.
- **Penyebab**: Repositori lokal sudah memiliki konfigurasi alamat remote dengan nama `origin`.
- **Solusi**:
  - Periksa alamat remote saat ini menggunakan `git remote -v`.
  - Jika ingin memperbarui ke alamat repository baru, jalankan:
    ```bash
    git remote set-url origin <URL_REPOSITORY_BARU>
    ```

### 4. Skor Google Lighthouse Rendah atau Tidak Stabil
- **Gejala**: Skor performa menunjukkan warna oranye atau merah padahal website statis berukuran kecil.
- **Penyebab**:
  1. Pengujian dilakukan di jendela browser biasa yang aktif dengan ekstensi pihak ketiga (adblocker atau extension lain menambah waktu pemrosesan).
  2. Gambar belum terkompresi sehingga ukuran berkas sangat besar.
- **Solusi**:
  - Selalu jalankan audit Lighthouse pada **Jendela Penyamaran (Incognito Window)** Google Chrome.
  - Kompres berkas gambar menjadi format WebP atau gunakan dimensi gambar yang sesuai dengan tampilan layar.

## 5. Template Konfigurasi `netlify.toml` untuk Website Statis

Berikut adalah contoh berkas konfigurasi standar yang dapat Anda salin ke proyek website statis Anda:

```toml
# netlify.toml - Konfigurasi Standar Website Statis

[build]
  publish = "."   # Direktori yang dipublikasikan ke server CDN Netlify

# Aturan Header Keamanan HTTP
[[headers]]
  for = "/*"
  [headers.values]
    X-Frame-Options = "DENY"
    X-Content-Type-Options = "nosniff"
    Referrer-Policy = "strict-origin-when-cross-origin"
```
