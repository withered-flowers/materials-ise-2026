## 1. Cheatsheet Perintah Netlify CLI

| Perintah | Deskripsi Fungsi |
| :--- | :--- |
| `npx netlify-cli login` | Membuka browser untuk otentikasi login ke akun Netlify. |
| `npx netlify-cli status` | Memeriksa status login, akun yang aktif, dan detail situs yang terhubung. |
| `npx netlify-cli dev` | Menjalankan server pengembangan lokal (Frontend + Serverless Functions). |
| `npx netlify-cli deploy` | Me-deploy situs ke lingkungan **Draft / Preview** (Bukan Live). |
| `npx netlify-cli deploy --prod` | Me-deploy situs langsung ke lingkungan **Production (Live)**. |
| `npx netlify-cli sites:list` | Menampilkan seluruh daftar situs yang ada di akun Netlify Anda. |
| `npx netlify-cli env:list` | Menampilkan daftar Environment Variables yang diset di Netlify Cloud. |
| `npx netlify-cli env:set KEY "VALUE"` | Menambahkan atau memperbarui Environment Variable di cloud. |
| `npx netlify-cli functions:logs` | Menampilkan *streaming log* eksekusi Netlify Functions secara live di terminal. |

## 2. Cheatsheet Perintah Dasar Git & GitHub

| Perintah | Deskripsi Fungsi |
| :--- | :--- |
| `git init` | Menginisialisasi repository Git baru di folder lokal. |
| `git status` | Melihat status perubahan file (staged, unstaged, untracked). |
| `git add .` | Menambahkan seluruh perubahan file ke penampungan (*staging area*). |
| `git commit -m "pesan"` | Menyimpan jepretan (*snapshot*) perubahan dengan pesan yang jelas. |
| `git push -u origin main` | Mengunggah commit lokal ke branch `main` di GitHub repository. |
| `git pull origin main` | Mengambil dan menggabungkan perubahan terbaru dari GitHub ke lokal. |

## 3. Matriks Troubleshooting Masalah & Solusi

### 1. Error HTTP 404 (Page Not Found)
* **Gejala**: Saat membuka URL Netlify, muncul tampilan "Page Not Found".
* **Penyebab Utama**:
  1. Nama berkas utama bukan `index.html` (misal: `Index.html` atau `home.html`).
  2. Direktori `publish` pada `netlify.toml` atau Netlify Dashboard tidak mengarah ke tempat `index.html` berada.
* **Solusi**:
  - Pastikan file bernama `index.html` (semua huruf kecil).
  - Jika aset statis berada di folder `public/`, pastikan `publish = "public"` di `netlify.toml`.

---

### 2. Error CORS (Cross-Origin Resource Sharing)
* **Gejala**: Console browser menampilkan `Access to fetch at ... has been blocked by CORS policy`.
* **Penyebab Utama**: Frontend memanggil URL backend domain berbeda tanpa header CORS yang sesuai.
* **Solusi**:
  - Gunakan **URL Rewrite** pada `netlify.toml`:
    ```toml
    [[redirects]]
      from = "/api/*"
      to = "/.netlify/functions/:splat"
      status = 200
    ```
  - Di JavaScript frontend, panggil endpoint dengan path relatif: `fetch('/api/nama-fungsi')`.

---

### 3. Error HTTP 500 (Internal Server Error / Function Invocation Failed)
* **Gejala**: Panggilan ke serverless backend gagal dengan kode status HTTP 500.
* **Penyebab Utama**: Terdapat *uncaught exception*, modul tidak ditemukan, atau sintaks TypeScript yang error saat runtime serverless.
* **Solusi**:
  - Jalankan `npx netlify-cli functions:logs` di terminal untuk melihat stack trace error.
  - Periksa apakah variabel lingkungan (`process.env.VAR_NAME`) bernilai `undefined`.

---

### 4. Environment Variables Tidak Terbaca di Serverless
* **Gejala**: `process.env.SECRET_KEY` bernilai `undefined` atau string kosong.
* **Penyebab Utama**: Variable baru ditambahkan di Netlify Dashboard *setelah* deployment terakhir dilakukan.
* **Solusi**:
  - Lakukan deploy ulang (`npx netlify-cli deploy --prod`) atau *Trigger Deploy* ulang di Netlify Dashboard agar variable baru di-inject ke dalam instance fungsi.

## 4. Contoh Berkas `netlify.toml` Serbaguna (Cheat Template)

Gunakan template `netlify.toml` berikut untuk proyek Fullstack Vanilla JS + TypeScript Netlify Functions:

```toml
# netlify.toml - Template Serbaguna

[build]
  publish = "public"            # Folder tempat file HTML/CSS/JS statis berada
  functions = "netlify/functions" # Folder fungsi serverless TypeScript

# 1. URL Rewrite untuk API Backend (Bebas Isu CORS)
[[redirects]]
  from = "/api/*"
  to = "/.netlify/functions/:splat"
  status = 200

# 2. Redirect Fallback untuk Single Page Application (SPA)
[[redirects]]
  from = "/*"
  to = "/index.html"
  status = 200

# 3. Security HTTP Headers
[[headers]]
  for = "/*"
  [headers.values]
    X-Frame-Options = "DENY"
    X-Content-Type-Options = "nosniff"
    Referrer-Policy = "strict-origin-when-cross-origin"
```
