## 1. Apa Itu Serverless Backend (Netlify Functions)?

Tradisionalnya, untuk menjalankan backend (seperti Express.js), Anda harus menyewa virtual server (VPS) yang menyala terus menerus 24 jam sehari. 

**Serverless Architecture** mengubah paradigma tersebut:
- Kode backend Anda dipecah menjadi fungsi-fungsi kecil (*Functions*).
- Server hanya akan "bangun" dan mengeksekusi kode saat ada permintaan (*request*) dari klien.
- Setelah memberikan tanggapan (*response*), server otomatis mati (*scale to zero*).
- **Keuntungan**: Sangat murah (ada gratis kuota bulanan yang melimpah di Netlify), tidak perlu mengurus pemeliharaan server, dan otomatis menangani trafik tinggi.

## 3. Anatomi Kode TypeScript Netlify Functions Modern

Netlify Functions versi terbaru menggunakan standar **Web Request & Response API** (Mirip dengan `fetch` bawaan browser dan Edge Runtime).

### Penjelasan Kode: `netlify/functions/hello.ts`

```typescript
import type { Context } from "@netlify/functions";

export default async (req: Request, context: Context) => {
  // 1. Membaca Query Parameter dari URL (contoh: ?name=Budi)
  const url = new URL(req.url);
  const name = url.searchParams.get("name") || "Developer Junior";

  // 2. Membaca Environment Variable dari server
  const secretKey = process.env.MY_SECRET_KEY || "Secret belum diset";

  // 3. Mengembalikan Response JSON
  return new Response(
    JSON.stringify({
      message: `Halo ${name}, selamat datang di Backend Netlify Functions!`,
      timestamp: new Date().toISOString(),
      customSecret: secretKey
    }),
    {
      status: 200,
      headers: {
        "Content-Type": "application/json",
        "Access-Control-Allow-Origin": "*" // Mengizinkan akses dari domain manapun
      }
    }
  );
};
```

### Penjelasan Kode: `netlify/functions/quotes.ts`

```typescript
import type { Context } from "@netlify/functions";

interface Quote {
  id: number;
  text: string;
  author: string;
}

const quotes: Quote[] = [
  { id: 1, text: "First, solve the problem. Then, write the code.", author: "John Johnson" },
  { id: 2, text: "Simplicity is prerequisite for reliability.", author: "Edsger W. Dijkstra" }
];

export default async (req: Request, context: Context) => {
  // Validasi Metode HTTP (Hanya izinkan GET)
  if (req.method !== "GET") {
    return new Response(JSON.stringify({ error: "Method not allowed" }), {
      status: 405,
      headers: { "Content-Type": "application/json" }
    });
  }

  const randomQuote = quotes[Math.floor(Math.random() * quotes.length)];

  return new Response(JSON.stringify(randomQuote), {
    status: 200,
    headers: { "Content-Type": "application/json" }
  });
};
```

## 4. Konfigurasi `netlify.toml` untuk Backend

Agar URL endpoint API terlihat rapi (`/api/hello` dan bukan `/.netlify/functions/hello`), kita dapat mengonfigurasi **URL Redirects/Rewrites** di file `netlify.toml`:

```toml
[build]
  functions = "netlify/functions" # Lokasi kode sumber fungsi TypeScript

# Rewrite URL /api/hello ke fungsi serverless
[[redirects]]
  from = "/api/hello"
  to = "/.netlify/functions/hello"
  status = 200

# Rewrite URL /api/quotes ke fungsi serverless
[[redirects]]
  from = "/api/quotes"
  to = "/.netlify/functions/quotes"
  status = 200
```

## 5. Mengelola Environment Variables (Variabel Rahasia)

Jangan pernah menyimpan kunci rahasia (seperti API Key, Database Password) di dalam file `.ts`. Gunakan Environment Variables!

### Cara 1: Mengatur via Netlify CLI

```bash
# Menambahkan Environment Variable baru di cloud Netlify
npx netlify-cli env:set MY_SECRET_KEY "KunciRahasiaSuperAman123"
```

### Cara 2: Mengatur via Netlify Dashboard UI

<Steps>
1. Buka situs Anda di [app.netlify.com](https://app.netlify.com).
2. Masuk ke **Site configuration** > **Environment variables**.
3. Klik **Add a variable** > **Single variable**.
4. Isi **Key**: `MY_SECRET_KEY` dan **Value**: `KunciRahasiaSuperAman123`.
5. Klik **Save**.
</Steps>

## 6. Uji Coba Lokal & Deployment Backend

<Steps>
1. **Instal Ketergantungan (Dependencies)**:
   ```bash
   cd sources/02-backend-ts
   npm install
   ```

2. **Jalankan Netlify Dev Server**:
   ```bash
   npx netlify-cli dev
   ```
   Netlify CLI akan secara otomatis mengompilasi TypeScript di latar belakang (*hot-reload*).

3. **Uji Endpoint di Browser atau Postman**:
   - `http://localhost:8888/api/hello?name=Siti`
   - `http://localhost:8888/api/quotes`

4. **Deploy Backend ke Netlify Production**:
   ```bash
   npx netlify-cli deploy --prod
   ```
</Steps>

## 7. Troubleshooting Masalah Serverless Backend

:::warning[Masalah: Error "Function invocation failed" (HTTP 500)?]
**Penyebab**: Terdapat sintaks error yang tidak tertangkap, *undefined variable*, atau modul eksternal yang gagal dimuat saat runtime.
**Solusi**: Periksa log eksekusi fungsi secara real-time di terminal dengan perintah `npx netlify-cli functions:logs` atau periksa tab **Logs** > **Functions** di Dashboard Netlify.
:::

:::warning[Masalah: Environment Variable bernilai undefined di Production?]
**Penyebab**: Environment variable ditambahkan setelah deployment selesai.
**Solusi**: Lakukan *re-deploy* (`npx netlify-cli deploy --prod`) agar Netlify memasukkan nilai environment variable terbaru ke dalam runtime fungsi.
:::
