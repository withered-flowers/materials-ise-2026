## Rencana Pembelajaran

Materi ini disusun secara bertahap bagi pemula, baik siswa SMA/SMK maupun mahasiswa tingkat awal, yang ingin mempublikasikan karya website ke internet dengan standar industri modern.

<CardGrid stack>
  <Card title="Modul 1: Konsep Dasar Deployment" icon="open-book">
    Mengenal pengertian deployment, perbedaan lingkungan **Local vs Production**, peran Domain dan DNS, keamanan HTTPS/SSL, serta konsep Content Delivery Network (CDN).
  </Card>
  <Card title="Modul 2: Penggunaan Git dan GitHub" icon="laptop">
    Memahami dasar *version control*, konfigurasi identitas Git, alur penyimpanan (*working directory*, *staging area*, *commit*), hingga menghubungkan dan mengunggah kode ke repository GitHub.
  </Card>
  <Card title="Modul 3: Deploy Website Statis ke Netlify" icon="rocket">
    Praktik langsung mempublikasikan website statis (HTML, CSS, dan JavaScript) ke Netlify melalui antarmuka web dashboard terhubung ke GitHub (CI/CD otomatis).
  </Card>
  <Card title="Modul 4: Benchmark Performa dengan Google Lighthouse" icon="star">
    Melakukan audit performa website menggunakan Google Lighthouse, memahami 5 metrik performa utama (FCP, LCP, CLS, TBT, Speed Index), menginterpretasikan 4 kategori skor evaluasi, dan menerapkan teknik optimasi aset.
  </Card>
</CardGrid>
